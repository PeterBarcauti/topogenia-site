La galerie

La galerie rassemble des modèles génériques, construits à partir des pratiques les plus courantes. Chaque modèle fournit une trame de départ cohérente, destinée à être confrontée au terrain et ajustée à votre fonctionnement. Un modèle ne décrit aucune organisation réelle. Les modèles ont été rédigés avec l'aide d'une intelligence artificielle, puis relus et confrontés à des référentiels publics.

Les modèles sont organisés par domaine. Pour chacun, vous pouvez récupérer un processus précis ou télécharger la collection complète dans un seul fichier.

Télécharger un modèle ou une collection

Un modèle est un fichier .pmap : du texte brut, lisible directement dans le Bloc-notes. Une collection est un fichier .pmaps de même nature, qui réunit l'ensemble des modèles d'un domaine.

Ouvrez la page d'un domaine et téléchargez le modèle ou la collection souhaitée. Topogenia ne va rien chercher sur internet : c'est votre navigateur qui télécharge le fichier.

Chaque modèle (.pmap) et chaque collection (.pmaps) est publié avec son empreinte SHA-256, affichée sur la page et regroupée dans un fichier sha256.txt, afin que vous puissiez vérifier que le fichier reçu est intact. Les images ne portent pas d'empreinte.

Vérifier l'empreinte

L'empreinte est une suite de caractères calculée à partir du contenu du fichier : la moindre modification la change. Ce contrôle est facultatif et ne prend que quelques secondes.

Sous Windows, ouvrez PowerShell dans le dossier du fichier téléchargé et lancez : Get-FileHash -Algorithm SHA256 nom-du-fichier

Comparez le résultat à l'empreinte affichée sur la page du domaine ou dans sha256.txt, sans tenir compte des majuscules et des minuscules. Si les deux suites diffèrent, n'ouvrez pas le fichier et téléchargez-le de nouveau.

Limite de ce contrôle : l'empreinte montre que le fichier n'a pas été altéré depuis sa publication ; elle ne dit pas qui l'a écrit. Publiée sur le même site que le fichier, elle ne protège pas non plus d'un site lui-même modifié : elle détecte un fichier abîmé en route, pas un site compromis.

Ouvrir dans Topogenia

Dans Topogenia, ouvrez Fichier, puis Ouvrir un fichier, et sélectionnez le fichier téléchargé. Un modèle seul (.pmap) est pris en charge dès la version 3.3 ; une collection (.pmaps) demande la version 3.4. En mode Serveur, cette opération est réservée à l'administrateur.

Pour un modèle seul, Topogenia crée un projet. Pour une collection, une fenêtre liste d'abord les processus qu'elle contient, tous cochés par défaut : décochez ceux qui ne vous sont pas utiles, ajustez si besoin le code proposé, puis validez pour créer un projet par processus retenu.

Aucune donnée n'est écrite avant votre validation. Annuler l'opération laisse vos projets intacts.

Si les téléchargements sont bloqués

Sur les postes soumis à des restrictions de téléchargement, la page de chaque modèle propose un bouton Copier qui place son contenu dans le presse-papiers. Ce bouton n'est pas disponible pour les collections : téléchargez la collection ou copiez ses modèles un par un.

Dans Topogenia, ouvrez la fenêtre Ouvrir un fichier et collez le texte dans la zone prévue. Un projet est créé exactement comme lors de l'ouverture d'un fichier.

L'empreinte SHA-256 se vérifie uniquement sur le fichier téléchargé tel quel : le texte copié n'est pas le fichier (selon l'éditeur de texte, les fins de ligne changent et avec elles l'empreinte), son empreinte ne se compare donc pas à celle de la page.

Adapter le modèle

Une fois importé, le modèle devient un projet ordinaire : renommez les couloirs, modifiez les étapes, ajoutez ou retirez des flux et précisez les responsabilités.

Reprenez-le avec les personnes qui font réellement le travail. Le modèle pose la trame habituelle ; vos exceptions, vos outils et vos règles internes en font votre véritable carte.

Certains modèles incluent des points à vérifier : ce sont des questions d'atelier à trancher ensemble lors de l'adaptation.
