Process templates

Swimlane maps ready to open in Topogenia, sorted by domain. A standard base, so you never start from a blank page.

The gallery

The gallery brings together generic templates, built from the most common practices. Each template provides a consistent starting framework, meant to be tested against the field and adjusted to the way you work. A template describes no real organisation. The templates were written with the help of artificial intelligence, then reviewed and checked against public references.

Templates are organised by domain. For each one, you can take a single process or download the full collection in one file.

Download a template or a collection

A template is a .pmap file: plain text, readable directly in Notepad. A collection is a .pmaps file of the same kind, which gathers all the templates of a domain.

Open the page of a domain and download the template or the collection you want. Topogenia fetches nothing from the internet: your browser downloads the file.

Each template (.pmap) and each collection (.pmaps) is published with its SHA-256 fingerprint, shown on the page and gathered in a sha256.txt file, so that you can check that the file you received is intact. The images carry no fingerprint.

Check the fingerprint

The fingerprint is a string of characters computed from the content of the file: the slightest change alters it. This check is optional and takes only a few seconds.

On Windows, open PowerShell in the folder of the downloaded file and run: Get-FileHash -Algorithm SHA256 file-name

Compare the result with the fingerprint shown on the domain page or in sha256.txt, ignoring upper and lower case. If the two strings differ, do not open the file and download it again.

Limit of this check: the fingerprint shows that the file has not been altered since it was published; it does not say who wrote it. Published on the same website as the file, it does not protect against a website that has itself been modified either: it detects a file damaged on the way, not a compromised website.

Open in Topogenia

In Topogenia, open File, then Open a file, and select the downloaded file. A single template (.pmap) is supported from version 3.3; a collection (.pmaps) needs version 3.4. In Server mode, this operation is reserved for the administrator.

For a single template, Topogenia creates one project. For a collection, a window first lists the processes it contains, all ticked by default: untick those you do not need, adjust the proposed code if necessary, then confirm to create one project for each process kept.

No data is written before you confirm. Cancelling the operation leaves your projects untouched.

If downloads are blocked

On workstations with download restrictions, the page of each template offers a Copy button that puts its content on the clipboard. This button is not available for collections: download the collection or copy its templates one by one.

In Topogenia, open the Open a file window and paste the text into the area provided. A project is created exactly as when a file is opened.

The SHA-256 fingerprint can only be checked on the downloaded file as it is: the copied text is not the file (depending on the text editor, line endings change, and the fingerprint with them), so its fingerprint cannot be compared with the one on the page.

Adapt the template

Once imported, the template becomes an ordinary project: rename the lanes, change the steps, add or remove flows and specify the responsibilities.

Review it with the people who actually do the work. The template sets out the usual framework; your exceptions, your tools and your internal rules make it your real map.

Some templates include points to check: these are workshop questions to settle together while adapting it.
